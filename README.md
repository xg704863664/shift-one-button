# SHIFT

a one-button game where Shift is the only control

A game made for **Game Off 2026**.

## Running it

Open the folder in **Godot 4.3** and press play, or grab a build from the
[releases page](https://github.com/xg704863664/shift-one-button/releases).

## Controls

    A / D      move
    SPACE      jump
    ESC        pause
    R          restart
    ENTER      start / retry
